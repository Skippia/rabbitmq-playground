## Limited retry (protection from poison messages) with exponential back-off

| Название | Описание | По умолчанию |
|------------|------------|------------|
| `FROM_QUEUE` | Очередь из которой необходимо забирать сообщения  | **nil** |
| `FROM_EXCHANGE` | Ексчейндж на которую должна быть подписана очередь  | **nil** |
| `FROM_ROUTINGKEY` | Роутинг кей с которым должна быть подписана очередь на эксчейндж  | **nil** |
| `PREFETCH` | prefetch_count - кол-во одновременно получаемых сообщений от консьюмера  | **50** |
| `FAIL`  | Эмуляция reject'ов на половину обрабатываемых сообщений  | **false** |
| `REJECTALL`  | Эмуляция reject'ов на все обрабатываемые сообщения  | **false** |
| `SLEEP`  | Эмуляция времени обработки сообщений, в миллисекундах  | **0** |  
| `RETRY_QUEUE`  | Создание очереди повторных попыток для этой очереди (не забудьте удалить очередь перед включением или отключением)  | **false** |
| `RETRY_QUEUE_TTL`  | TTL для очереди повторных попыток, ms  | **15000** |
